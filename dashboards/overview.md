# Gráficos e métricas

O Dashboard reúne gráficos e cartões de métrica construídos em cima dos dados
das suas tabelas, servindo como um painel de indicadores do ambiente.

## O que aparece no Dashboard

Dependendo da configuração e das permissões, o Dashboard mostra:

- **Cartões de métrica** — números resumidos, como total de registros de uma
  tabela, contagem de usuários ou qualquer outra contagem relevante.
- **Gráficos** — visualizações construídas sobre os dados das tabelas, para
  acompanhar tendências e distribuições.
- **Atividade recente** — um resumo do que mudou recentemente no ambiente.

## Quem vê o quê

O acesso ao Dashboard, assim como a qualquer outra área, respeita as
[permissões do usuário](../tables/permissions.md) — os números e gráficos
exibidos refletem apenas os dados que a pessoa logada tem permissão para
enxergar.
