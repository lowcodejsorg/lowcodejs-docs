# Documento

A visualização de Documento exibe os registros como texto corrido, agrupado
por categoria — o formato mais próximo de uma base de conhecimento ou wiki,
em vez de uma tabela ou grade de cartões.

## Campos necessários

Para a visualização de Documento ficar disponível, a tabela precisa ter:

- Um campo do tipo **Categoria**, usado para agrupar e organizar a navegação
  entre os documentos (ex.: capítulos, seções).
- Um campo de **texto longo**, usado como corpo do documento — com suporte a
  formatação rica (títulos, listas, links).

## Como funciona a navegação

Os nós da árvore de categoria que apenas agrupam (sem conteúdo próprio)
funcionam como índice/sumário; os nós selecionáveis abrem o conteúdo do
registro correspondente. Isso permite organizar uma base de conhecimento
inteira com hierarquia de capítulos e seções.

## Quando usar

- Documentação interna de processos.
- Bases de conhecimento e FAQs.
- Manuais e políticas organizadas por tema.

## Começando com um modelo pronto

Ao criar uma tabela nova, o modelo pronto de Documento já vem com o campo de
categoria e o campo de texto longo configurados.
