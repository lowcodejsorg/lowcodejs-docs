# Visão geral das 9 visualizações

Toda tabela pode ser exibida de 9 formas diferentes. A visualização não muda
os dados nem a estrutura da tabela — apenas como ela é apresentada e
interagida. Você pode alternar de visualização a qualquer momento, e os
estilos disponíveis dependem dos campos que a tabela já tem (por exemplo, o
Kanban exige um campo de dropdown para servir de coluna).

## As 9 visualizações

| Visualização | Em poucas palavras | Quando usar |
| --- | --- | --- |
| **Lista** | Tabela tradicional em linhas e colunas | O padrão para quase qualquer cadastro |
| **Galeria** | Cartões organizados em grade, com destaque visual (ex.: imagem) | Catálogos, portfólios |
| **Documento** | Conteúdo organizado como texto corrido, agrupado por categoria | Bases de conhecimento, wikis |
| **Cartões (Card)** | Cada registro como um cartão com imagem, título e descrição | Produtos, perfis, itens visuais |
| **Mosaico** | Grade densa, estilo mural de imagens | Galerias de imagem, moodboards |
| **Kanban** | Quadro com colunas (baseadas num campo dropdown) e cartões arrastáveis | Fluxo de tarefas, funil de vendas |
| **Fórum** | Canais de discussão com mensagens e respostas | Discussões em equipe, suporte |
| **Calendário** | Eventos posicionados num calendário, por data de início/fim | Agendamentos, prazos, eventos |
| **Gantt** | Linha do tempo de tarefas, mostrando duração e sequência | Planejamento de projeto |

## Modelos prontos

Para a maioria das visualizações mais estruturadas (Kanban, Cartões, Mosaico,
Documento, Fórum, Calendário), a própria tela de criar uma tabela nova
oferece modelos prontos, com os campos certos já configurados — é o caminho
mais rápido para começar, em vez de montar os campos um a um manualmente.
Quais modelos aparecem ali é controlado em **Configurações** → "Modelo de
Tabelas".

## Como a plataforma decide o que é possível

Cada visualização depende de a tabela ter os campos certos para funcionar.
Por exemplo:

- **Kanban** e **Gantt** pedem uma estrutura de tarefas (um campo de
  dropdown servindo de lista/coluna, mais um grupo de campos de tarefas).
- **Fórum** pede uma estrutura de mensagens (um grupo de campos de
  mensagens com autor, texto e data).
- **Calendário** pede campos de título, descrição, datas de início e término
  e uma cor.
- **Documento** pede um campo de categoria e um campo de texto longo.
- **Cartões** e **Mosaico** pedem um campo de arquivo (imagem) junto com
  texto curto e longo.
- **Lista** e **Galeria** estão sempre disponíveis, em qualquer tabela.

Se os campos certos não existirem ainda, a visualização correspondente
simplesmente não aparece como opção — adicione os campos necessários (ou
parta de um modelo pronto) para liberá-la.
