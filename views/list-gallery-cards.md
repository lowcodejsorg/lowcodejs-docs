# Lista, Galeria, Cartões e Mosaico

Quatro das visualizações mais simples de configurar — todas exibem os
mesmos registros, apenas organizados de um jeito diferente.

## Lista

A visualização padrão de toda tabela nova: uma tabela tradicional em linhas
e colunas, com uma coluna por campo configurado para aparecer na listagem.

Recursos típicos:

- Ordenação por coluna.
- Filtros na lateral, usando os campos marcados como "mostrar no filtro".
- Seleção múltipla de linhas para ações em lote.
- Esconder/mostrar colunas e reordenar/redimensionar.

Está sempre disponível, em qualquer tabela, independentemente dos campos
configurados.

## Galeria

Organiza os registros em um grid de cartões, com um foco maior na
apresentação visual de cada item do que a Lista. Também está sempre
disponível.

## Cartões (Card)

Cada registro aparece como um cartão com imagem de destaque, título e
descrição — parecido com a Galeria, mas pensado para quando a tabela tem uma
estrutura mais definida de mídia e texto.

Para ficar disponível, a tabela precisa ter ao menos um campo de arquivo
(para a imagem), um campo de texto curto (título) e um de texto longo
(descrição).

## Mosaico

Uma grade mais densa, no estilo de um mural de imagens — boa para catálogos
visuais onde o volume de itens é grande e o destaque principal é a imagem.

Tem os mesmos pré-requisitos de campo que a visualização em Cartões (arquivo
+ texto curto + texto longo).

## Trocando de visualização

A troca de visualização é feita pela própria tela da tabela, sem afetar os
dados. Visualizações diferentes podem ser salvas e reutilizadas conforme a
necessidade de cada público (por exemplo, uma visão de Lista para quem
administra e uma Galeria para quem só consulta).
