# Clonar Tabela

Cria uma ou mais tabelas novas copiando a estrutura de tabelas já existentes
no ambiente, com ou sem os registros — e é também o caminho para usar os
**modelos prontos** de visualização.

## Clonando uma tabela existente

Escolha uma tabela do ambiente atual como origem e decida:

- Copiar **somente a estrutura** (campos, configurações, permissões) ou
  **estrutura e dados** (os registros também).
- O nome da(s) tabela(s) de destino.

É uma forma rápida de reaproveitar uma estrutura já testada, ou de criar uma
cópia de trabalho/teste de uma tabela de produção.

## Usando um modelo pronto

Ao criar uma tabela nova (**Tabelas** → Nova tabela → Usar um Modelo), você
pode partir de um modelo já configurado com os campos certos para uma
visualização específica:

| Modelo | Visualização que habilita |
| --- | --- |
| **Kanban** | [Kanban](../views/kanban.md) (e também Gantt) |
| **Cartões** | [Cartões](../views/list-gallery-cards.md) |
| **Mosaico** | [Mosaico](../views/list-gallery-cards.md) |
| **Documento** | [Documento](../views/document.md) |
| **Fórum** | [Fórum](../views/forum.md) |
| **Calendário** | [Calendário](../views/calendar-gantt.md) |

Partir de um modelo pronto evita ter que descobrir manualmente a combinação
exata de campos que cada visualização mais estruturada exige.
